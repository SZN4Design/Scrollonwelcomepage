the statement wraps naturally, the buttons stack, and spacing tightens.

Cream text: styles.css -> --cream
Sand accent: styles.css -> --sand
Scroll pacing: styles.css -> .zoom-line min-height
Zoom strength: index.html -> data-max-scale
